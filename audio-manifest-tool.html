Générateur audio — fonctionne 100% sur iPhone

Cet outil tourne entièrement dans ton navigateur (rien n'est envoyé nulle part). Il regroupe tes fichiers audio en quelques gros fichiers .zip (au lieu de milliers de petits fichiers), pour que l'upload sur GitHub reste faisable depuis l'app Fichiers de l'iPhone.

1
Sélectionne tes fichiers audio
Fichiers attendus : id_mot_categorie.mp3 (ex. 42_abandon_mot.mp3). Sur iPhone : bouton ci-dessous → Parcourir → ton dossier audio → Tout sélectionner en haut à droite.
2
Génère les zips
Regroupe automatiquement les fichiers en paquets d'environ 20 Mo (limite de l'upload web GitHub : 25 Mo/fichier).
3
Télécharge chaque fichier
Appuie sur chaque bouton : iOS propose "Enregistrer dans Fichiers" (choisis un dossier, par ex. Téléchargements).
4
Mets-les dans le repo GitHub (depuis Safari, sans PC)
Sur github.com (Safari iPhone), dans ton dépôt :
• audio-index.json → Add file → Upload files, dépose-le dans data/ (remplace l'ancien)
• chaque audio-part-N.zip → Add file → Upload files, dépose-les dans un dossier audio-zips/ à la racine du repo (tape audio-zips/nomdufichier.zip au moment de l'upload pour créer le dossier)
• valide (Commit changes)
